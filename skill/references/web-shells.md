# 拟态新闻站创作速查

## 目标

让作品首先像一个可正常阅读的离线新闻网站，再通过异常报道、条件链接和世界状态揭示文字冒险。网页只改变信息组织；剧情导航仍完全使用节点 `choices`。

## 最小配置

只调用一次：

```jsonc
story_set_meta {
  "title": "项目标题",
  "site": {
    "kind": "news",
    "name": "玩家看到的站名",
    "tagline": "可选固定口号",
    "locale": "可选地区或频道"
  }
}
```

节点按需增加：

```jsonc
"page": {
  "layout": "frontpage",
  "section": "本地",
  "headline": "页面标题",
  "byline": "作者",
  "timestamp": "故事内时间"
}
```

`layout`：

- `frontpage`：入口/栏目首页，适合 2–6 个报道 choice；
- `article`：普通长报道，默认；
- `bulletin`：关键快讯或紧急通知，少量使用。

## 硬规则

1. 报道、栏目、附件和返回入口全部使用现有 choices；`when/effects` 照常控制显隐和结果。
2. 不生成 `<a>`、独立 URL、浏览器历史路由、登录框、用户数据表单、远程资源或 JavaScript。
3. 站名/口号/地区只配置一次；节点不要重复页眉和版权文字。
4. `page` 不承载剧情状态。关键事实必须出现在 `text/blocks`，关键入口必须有公平文本线索。
5. 新闻页面是常规阅读界面；`stage` 只用于特殊剧情与过场，结束后用 `stage:"clear"` 返回网页。
6. 运行时至少点击首页→报道→条件秘密入口，并确认返回、证据效果、存档和结局。
