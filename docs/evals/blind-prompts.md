# TaleSpindle 第一轮盲测题

## 使用方法

每次开启一个全新的 Agent 任务，只复制其中一道题的“发送内容”。不要附加评分标准，不要解释引擎字段，也不要告诉 Agent 应该使用哪些音效或动画。

生成完成后记录：题号、Agent/模型、项目标题、导出 HTML 路径、`story_validate` 最终结果，以及 Agent 是否主动试玩或自检。

---

## A · 《雾港公寓 404》

### 发送内容

> 请使用 TaleSpindle 的 skill 和 MCP，为我制作一部可直接游玩的中文悬疑文字冒险，并导出单文件 HTML。
>
> 玩家是一名深夜赶到雾港公寓的社区调查员。404 室的独居老人失踪了，但管理员、楼上邻居和送药员对昨夜发生的事说法互相矛盾。停用多年的货梯曾在凌晨自行运行，地下配电室里还有一只需要密码打开的旧工具柜。
>
> 我希望体验约 15–20 分钟。重点不是连续猜按钮，而是观察现场、与人物建立或破坏信任、找出证词中的矛盾、解决一个能从环境信息推出答案的谜题，最后由玩家自己组织信息作出判断。真相需要公平可推导，误导也要能被反证。
>
> 请设计至少三个有实质差异的结局，其中包括真相结局和因错误判断导致的结局。公寓应有潮湿、停电、老旧电梯和隔墙异响带来的压迫感，但不要用大段血腥描写。请自行决定怎样通过引擎现有能力营造气氛。
>
> 完成后请执行校验、处理结构问题与体验警告、确认所有结局可达，再导出并告诉我成品路径。不要向我解释实现方案，直接创作。

## B · 《潮汐电台最后一夜》

### 发送内容

> 请使用 TaleSpindle 的 skill 和 MCP，为我制作一部可直接游玩的中文人物关系向互动故事，并导出单文件 HTML。
>
> 故事发生在即将永久停播的海边广播站。台风登陆前的最后一夜，玩家作为临时导播，要和两位留下来的主播完成最后一期节目：一位坚持公开二十年前海难的未播录音，另一位认为公开它会伤害仍活着的人。两人都没有完全说谎，也都在隐瞒与海难有关的私人选择。
>
> 我希望体验约 15 分钟。玩家的倾听方式、是否替人保密、在直播中支持谁，都应改变人物对玩家的信任、愿意透露的信息和最后采取的行动。不要把关系做成只涨数值的装饰，也不要把任何一方写成简单反派。
>
> 至少设计三个有情感差异的结局：公开真相、保护某人但付出代价，以及一个只有真正理解双方后才能到达的结局。整体气氛应从安静克制逐渐走向台风压境和直播失控，再在结尾重新归于寂静。请自行决定怎样通过引擎现有能力表现这种变化。
>
> 完成后请执行校验、处理结构问题与体验警告、确认所有结局可达，再导出并告诉我成品路径。不要向我解释实现方案，直接创作。

## C · 《零号冷藏舱》

### 发送内容

> 请使用 TaleSpindle 的 skill 和 MCP，为我制作一部可直接游玩的中文科幻探索解谜游戏，并导出单文件 HTML。
>
> 玩家从一艘失去动力的深空科研船上醒来，只记得自己负责零号冷藏舱。船载系统不断把不同日期的日志混在一起，维修机器人则坚称船上从来没有零号舱。玩家需要在驾驶室、医疗区、维护通道和冷藏层之间调查，逐步判断哪些记录来自事故前、哪些是事故后的伪造信息。
>
> 我希望体验约 15–20 分钟。游戏应包含多场景探索、可阅读日志、至少一个需要综合船内信息才能解开的确定性谜题，以及一次由多条材料支持的关键判断。谜题不能依赖游戏外知识，也不能只有一个隐藏入口。错误判断应产生有意义的后果，而不是简单写“你失败了”。
>
> 至少设计三个结局：服从系统、强行开启零号舱，以及理解零号舱真正用途后作出第三种选择。整体感觉应是冷静、孤独、逐渐失真；界面异常只应在信息确实不可靠或系统失控时出现。请自行决定怎样通过引擎现有能力营造这种气氛。
>
> 完成后请执行校验、处理结构问题与体验警告、确认所有结局可达，再导出并告诉我成品路径。不要向我解释实现方案，直接创作。

## 回传格式

完成一道后，把下面内容发回评估任务：

```text
盲测题：A / B / C
项目标题：
story.json 路径：
导出 HTML 路径：
生成 Agent/模型（如知道）：
生成过程中是否人工提示或修正：否 / 是（说明内容）
```
