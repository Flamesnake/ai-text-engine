# 拟态网页外壳

拟态网页让作品开场看起来像故事世界中的真实网站，同时继续使用 TaleSpindle 的节点、选项、条件、效果、存档和 walk。网页只是信息组织与视觉隐喻，不是第二套剧情路由。

当前首个纵向切片支持 `news` 新闻站。论坛、博客和邮件将在新闻站经过作品校准后再决定是否进入核心。

## 全局站点配置

用一次 `story_set_meta` 设置站点身份：

```jsonc
{
  "title": "潮汐档案",
  "site": {
    "kind": "news",
    "name": "汐见晚报",
    "tagline": "潮水退去后，事实仍在。",
    "locale": "汐见町"
  }
}
```

- `name` 是玩家在网页抬头看到的站名，与项目真实标题分离。
- `tagline` 是站点长期口号，不应逐节点重复。
- `locale` 是短地区或频道标识。
- 不支持真实品牌仿冒、登录框、表单收集、远程请求或追踪脚本。

## 节点页面语义

节点继续提供 `text`、`blocks` 和 `choices`，只额外声明少量 `page` 元数据：

```jsonc
{
  "id": "frontpage",
  "objective": "从当晚报道中找出日期矛盾",
  "text": "市政厅称旧灯塔将在今晚完成最后一次值守。",
  "page": {
    "layout": "frontpage",
    "section": "本地",
    "headline": "旧灯塔将在今日永久关闭",
    "byline": "闻舟",
    "timestamp": "8 月 31 日 18:40"
  },
  "choices": [
    { "label": "查看灯塔值班员专访", "target": "interview" },
    { "label": "打开三年前的事故旧闻", "target": "archive_report" }
  ]
}
```

页面布局：

- `frontpage`：入口或栏目首页，选项显示为两栏相关报道；移动端退化为单栏。
- `article`：标准长报道；省略 `layout` 时默认使用。
- `bulletin`：少量关键快讯或紧急通知，不应作为普通段落的默认外观。

`headline` 缺省时依次回退到 `objective`、作品副标题和项目标题。`section`、`byline`、`timestamp` 都是展示字符串，不参与逻辑。

## 导航与隐藏玩法

所有可点击报道、栏目、附件和“返回首页”必须仍是 `choices`：

- `target` 指向已有节点；
- `when` 控制报道是否出现；
- `effects` 发放证据、文档、记忆或切换 world/phase；
- walk、DOM 见证和存档因而可以理解整个网站。

不要生成独立 URL、隐藏 `<a>`、真实浏览器历史、CSS-only 密道或 JavaScript 路由。新闻站可以在表面维持正常阅读体验，再通过异常报道、条件链接和 world/phase 进入秘密路线；但关键入口应有公平的文本线索。

## Token 与内容边界

- 站点名、口号和地区只配置一次；节点不要复制页眉、导航栏或版权信息。
- `page` 只写当前页面实际需要的差异，普通文章通常只需 `headline` 与 `section`。
- 正文继续放在 `text/blocks`，不要同时复制进 `headline` 或选项。
- 同一个“返回首页”节点可以汇流复用，但 choice 的 `response` 应承接玩家刚才查看的内容。
- 拟态外壳不要求每个节点都有 `page`；无元数据节点会使用安全的 article 回退。

## 舞台与过场

拟态新闻页面是常规阅读界面。`stage` 只用于特殊剧情表现和过场动画，例如网页彻底崩坏后进入故事现场、关键真相重演或结局定格。普通报道、调查和常规人物对话不要启用舞台；需要返回网页时用 `stage: "clear"`。

## 可访问性与验收

- 选项保持原生按钮，可使用键盘和屏幕阅读器操作。
- 页眉工具使用语义化 `nav`，正文标题使用页面级标题。
- 小屏幕自动单栏，无字体或样式时内容顺序仍成立。
- 单文件 HTML 不加载远程字体、图片、统计或脚本。
- 运行时验收至少真实点击一条首页→文章→秘密入口路线，并确认条件链接、证据效果、返回路径和结局仍正确。
